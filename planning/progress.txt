## 2026-03-22 - FCF-020-002
- Implemented core forecast engine — day-by-day projection
- Files created: lib/cash-flow-engine.js, test/cash-flow-engine.test.js
- **Learnings:**
  - Pure function pattern continues to pay off — computeForecast takes fully materialized inputs, 29 tests run in <500ms with zero DB setup
  - Reused computeExpectedNextDate, addDays, addMonths, parseDateOnly from recurring-detector.js — no duplication
  - Liability payments need manual monthly re-anchoring (addMonths + Math.min for short months) since they don't use Feature 19 schedule anchors
  - Safety counter (500 iterations) prevents infinite loops in recurring projection when frequency produces unexpected null
  - Confidence band formula: linear interpolation between anchor points (0→0%, 7→5%, 30→15%, 90→25%), capped at 25%

## 2026-03-22 - FCF-020-004 + FCF-020-004A
- Implemented monthly outlook summaries and excess liquidity detection as pure functions
- Files modified: lib/cash-flow-engine.js, test/cash-flow-engine.test.js
- **Learnings:**
  - computeMonthlyOutlook aggregates forecast events by type using a switch on event.type — clean separation of income/recurring/discretionary/liability/planned
  - Month chaining: end balance of month N = start of month N+1 via running accumulator
  - detectExcessLiquidity uses projected MINIMUM balance (conservative), not current or month-end
  - Reserve target formula: max(safety_floor, committed_monthly × reserve_months, explicit_override)
  - recommendation_level thresholds: none (excess=0), modest (0 < excess < committed), strong (excess >= committed)
